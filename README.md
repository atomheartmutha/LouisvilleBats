# ⚾ Road to the Bats — Ballpark to Browser

> An interactive Louisville Bats online baseball video game for kids and families, built for **HackKentucky 2026**.  
> Sponsored by **Carter Davis & the Louisville Bats**, powered by **Google Gemini API** and hosted on **Vultr Cloud**.

---

## 🌟 Overview

Physical kids' activity books at Louisville Slugger Field have seen declining engagement, leaving the Bats with unpredictable seasonal printing estimates. **Road to the Bats** modernizes youth fan entertainment by bringing the ballpark directly into the browser!

Accessible via **in-stadium QR codes** on concourse signs, souvenir cups, and game programs, or embedded directly onto **batsbaseball.com**, the game gives young fans an instant arcade baseball experience where solving baseball math challenges powers up towering home runs into the Ohio River.

---

## 🎮 Key Features

1. **⚾ Louisville Slugger Field Batting Derby**:
   - HTML5 Canvas baseball physics with pitch timing, sweet spot detection, and distance calculation.
   - Outfield wall targets (325 ft down the lines, 405 ft to straightaway center).
   - Dynamic crowd effects, hit particle trails, and play-by-play announcer reactions.

2. **⚡ Math Power-Up Mechanic**:
   - Solve age-appropriate baseball math questions (Ages 5-8, 9-11, 12+) to supercharge the bat.
   - Correct answers activate a **3x Golden Slugger Power-Up** for a guaranteed tape-measure blast splashing into the Ohio River!

3. **👕 Locker Room & Custom Rookie Card**:
   - Customize player name, jersey number, and official Bats uniform themes (Bats Red, Midnight Navy, Home White, Slugger Gold).
   - Generates a collectible rookie baseball card with an **AI Scouting Report** generated by Gemini.

4. **🦇 Buddy Bat's Dugout & Trivia**:
   - Chat with the official Louisville Bats mascot for coaching tips and positive reinforcement.
   - Test baseball smarts with interactive Bats trivia.

5. **📱 In-Stadium QR Code Station**:
   - Built-in QR code generator so fans can scan with their phone camera and play instantly with zero downloads.

## 🚀 Quick Start (Local Development)

### Prerequisites
- Node.js 18+ (Node 22 LTS recommended)
- npm 9+

### 1. Run the Server
From the project folder:

```bash
# Start local server
npm start
```
Or for auto-reloading during development:
```bash
npm run dev
```

### 2. Play in Browser
Open [http://localhost:3000](http://localhost:3000) in your web browser.

---

## 🤖 Google Gemini API Configuration

1. Get an API key from [Google AI Studio](https://aistudio.google.com/) or activate your MLH student credits.
2. Edit `.env` in the root folder:
   ```env
   GEMINI_API_KEY=your_key_here
   ```
3. Restart the server. The game will automatically switch from fallback mode to live generative AI!

See [gemini-setup-guide.md](gemini-setup-guide.md) for full details.

---

## ☁️ Vultr Cloud Deployment

Deploy in one command to a Vultr Cloud Compute instance:

```bash
./scripts/deploy-vultr.sh <YOUR_VULTR_IP>
```

Or deploy with Docker:
```bash
docker compose up -d --build
```

See [vultr-deploy-guide.md](vultr-deploy-guide.md) for step-by-step instructions.
